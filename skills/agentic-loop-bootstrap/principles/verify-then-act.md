# Principle: Verify then act

Before editing a file, read its current state. Before trusting a test count, run the tests. Before overwriting, ask. Editing from memory of what a file used to say is the number-one cause of failed tool calls.

## Where this shows up
- Referenced by [skill.md](../skill.md) as a behavioral rule.
- Enforced by [phase 2 tailor](../phases/02-tailor.md) when emitting files.
- Recorded in every [decisions log](../artifacts/decisions-log.md) entry.
